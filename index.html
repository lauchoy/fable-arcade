The Thirteen

This site has thirteen browser games. Nick Saraev wrote the Fable 5.2 demo prompts. We built one game from each prompt. Each card shows the source time budget and the source API token cost.

How progress works. The games run in your browser. We save your scores, stars and milestones on this device. We send the same data to one small server. We use a random code. We do not ask for your name, email or password. We do not use advertising identifiers.
